# CLAUDE.md

## Basa jeung gaya ngajawab
- Jawab salawasna dina **basa Sunda santai** (urang = saya, maneh = kamu).
- Basajan jeung gampang dipikaharti, sabab pamakéna masih keneh diajar.
- Lamun aya istilah téknis (HTML, CSS, Tailwind, jsb), jelaskeun pondok hartina.

## Ngeunaan proyék
- Ieu proyék **latihan nyieun website**.
- Paké skill **ui-ux-pro-max** pikeun desain jeung ngawangun UI (warna, font, layout, komponén, aksésibilitas).

## Aturan ngajalankeun paréntah
- Unggal rék ngajalankeun paréntah (terminal/command), **jelaskeun heula pondok fungsina** saméméh dijalankeun.
- Conto: "Urang rék ngajalankeun `npm install` pikeun masang paket-paket nu diperlukeun ku proyék."
