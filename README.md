# Seerip Betta

Landing page untuk **Seerip Betta**, usaha kecil ikan cupang hias pilihan seperti Halfmoon, Plakat, Crowntail, dan lainnya. Pengunjung bisa melihat koleksi ikan dan memesan langsung lewat WhatsApp.
